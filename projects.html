TTD Seva Booking Autofill

A browser userscript that automates the repetitive parts of booking seva tickets on the TTD portal — the parts that cost minutes per pilgrim during high-demand booking windows.

  • Full-form automation: pilgrim details, ID/Aadhaar selections, email presets and gender fields across multiple pilgrims, filled from saved presets.
  • Floating in-page UI to pick presets and trigger fills — no extensions store, no server, everything runs client-side.
  • Redesign-proof selectors: re-adapted the DOM selectors after the portal's layout changed, keeping the tool working across old and new site versions.
  • Deliberate limits: no automated login or captcha solving — the user stays in control; the tool only removes repetitive typing.

3D Portfolio Experience

A portfolio you don't scroll so much as travel through — a student character walks a 3D path, stops at each section and looks around while my profile appears along the journey.

  • Scroll-driven movement: the visitor's scroll controls the character's journey, giving a clear, understandable sequence through the content.
  • Real debugging: chased down a 3D engine loading failure where the engine wouldn't initialize — and built an accessible fallback portfolio so every visitor still gets a working site while it's fixed.
  • Cinematic detail: the character stops, looks around and the sections reveal themselves — the portfolio behaves like a small game.
